# SEIF Family — نموذج واجهة مشاركة الشاشة

هذه نسخة أولية وآمنة لواجهة موافقة واضحة باللغة العربية.

## ما الذي تفعله؟
- تعرض شرحًا واضحًا قبل اختيار «موافق» أو «إلغاء».
- تستخدم زر موافق أحمر وزر إلغاء أبيض.
- لا تجمع بيانات ولا تتصل بأي جهاز.
- لا تشغّل الكاميرا أو الميكروفون ولا تخفي نفسها.

## ما الذي لا تفعله؟
هذه الواجهة **ليست تطبيق مراقبة ولا تمنح تحكمًا عن بُعد**. مشاركة شاشة Android الفعلية تتطلب تطبيقًا مناسبًا، وصلاحيات النظام، وموافقة ظاهرة على الهاتف. يجب أن تبقى المشاركة واضحة وقابلة للإيقاف.

## تجربة الصفحة
افتح `index.html` في المتصفح، أو فعّل GitHub Pages من إعدادات المستودع لنشر صفحة الواجهة.
